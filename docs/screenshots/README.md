# SkillLinked - Screenshots Guide

Is folder mein ye screenshots save karo:

| File Name | Kahan se lena hai |
|-----------|-------------------|
| `hero.png` | Landing page → http://localhost:5173 |
| `login.png` | Login page → http://localhost:5173/auth/login |
| `signup.png` | Signup page → http://localhost:5173/auth/signup |
| `dashboard.png` | Dashboard → http://localhost:5173/app/dashboard |
| `networking.png` | My Network → http://localhost:5173/app/networking |
| `jobs.png` | Jobs page → http://localhost:5173/app/jobs |
| `messaging.png` | Messages → http://localhost:5173/app/messaging |
| `admin.png` | Admin panel → http://localhost:5173/app/admin |

## Kaise Save Karo?
1. Browser mein page open karo
2. `F12` dabao → Network tab
3. Ya sirf `Windows + Shift + S` se screenshot lo
4. Is folder mein save karo same name se

## README mein Image kaise dikhegi?
Jo screenshots tum yahan save karogi, woh README mein automatically 
`docs/screenshots/` path se load hongi.
